# 阅卷有方 v2.3 · B 站录屏操作与口播讲稿

版本：2.3.0 · 更新：2026-11-13。建议成片 6–7 分钟，口播约 5 分钟，给鼠标操作、切页和重点字幕留时间。下面的按钮名称与当前中文版一致。新版已采用 shadcn-admin 布局和 Magic UI 组件，原来的班级、评语和复核操作保持一致。

## 视频定位与标题

推荐标题：**我做了一个开源阅卷助手：按题批改、常用评语、班级考试记录都能管理**

备选标题：

- 给老师做的 AI 阅卷工作台：先初评，再复核，还能保存多个班级的考试
- 不只是给分：这个开源工具把试卷、评语和历史考试放在一起

封面文字：**多班级 · 多考试 / AI 初评，老师确认**。展示班级管理和原卷复核截图即可。不要使用“100% 准确”“全自动替代老师”“一分钟批完全年级”等未经验证的宣传语。

## 录制前准备

1. 打开 [中文版](https://jianshengchuanchaun.github.io/paper-grading-assistant/zh/)。建议用专门的演示浏览器配置，避免录到真实学生资料或现有教学记录。
2. 点击「体验示例」，生成虚构学生、试卷和成绩。内置演示不会调用 AI，展示时保留界面上的“示例”标识。
3. 如需拍摄导入步骤，下载 [虚构中文示例试卷](demo-materials/demo-paper-zh.jpg)。它由本项目演示程序生成，不含真实学生资料。
4. 不需要为了录制填写真实密钥。模型设置可以展示空表单；如单独录真实接口流程，请避免录到密钥、真实学生姓名、学号及答案原件。
5. 画面建议 1920×1080，浏览器缩放 100%–110%。每次点击后停 1–2 秒；需要滚动时缓慢滚动，让观众看清按钮与状态。
6. 开场可以先录班级列表和按题复核的近景，后期放到视频前 10 秒。下面正文按一条完整流程录制。

## 分镜与完整口播

**可选 15 秒界面展示：** 开场扫过新的数据卡片和绿色评分标准提示卡，点左上角收起 / 展开导航；按 Ctrl+K（Mac 为 Command+K），输入「常用评语」，回车打开，再返回工作台。口播可以说：“这次也把界面重新整理了。常用功能能直接搜索，侧边栏可以收起来，手机上也能打开菜单切换。”手机录屏时使用左上角菜单打开导航。

### 00:00–00:25｜从老师的实际工作说起

**画面操作：** 展示有内容的示例工作台，依次扫过「班级与批次」「常用评语」「按题复核」。

**口播：**

> 如果你同时带几个班，批卷子的麻烦，往往不只是算分：同一种问题要反复写评语，上周和这周的考试也要分开保存。于是我做了这个开源小工具，叫“阅卷有方”。它把试卷、评分标准、教师复核和历史考试放在一个工作台里。今天带你完整走一遍怎么用。

**字幕：** AI 辅助初评 · 教师掌握最终成绩。

### 00:25–00:55｜打开就能体验，中英文都能用

**画面操作：** 指向「体验示例」及示例说明，切换一次右上角 English，再切回简体中文。

**口播：**

> 项目提供中文和英文两个入口，链接放在简介里。第一次打开，可以先点“体验示例”，不需要账号，也不需要 API 密钥。这里的学生、试卷和分数都是虚构的，主要用来体验操作流程，不代表真实模型的批改效果。切换语言会改变界面，但不会自动翻译老师已经输入的试卷和评语。

### 00:55–01:45｜新建班级和考试，旧记录自动保留

**画面操作：** 进入「班级与批次」→「我的班级」旁的加号 → 名称填写“演示一班”，备注填写“2026 秋季” → 保存。点击「新建批次」，名称填写“数学第四单元随堂测验”，班级选“演示一班”，日期任选录制日期，勾选「复用当前考试的评分标准」→ 确认。

**口播：**

> 先把班级和考试建好。比如我新建一个“演示一班”，再为它建立这次单元测验。一个班级可以有多场考试，不同班级也各自管理。这里可以选择复用当前考试的评分标准，但学生和成绩不会跟着复制。新建以后，刚才的示例考试仍然保存在历史记录里，不会被清空。

**字幕：** 新考试独立保存；旧考试保留；只按选择复用评分标准。

### 01:45–02:25｜先定评分依据，再导入试卷

**画面操作：** 打开「评分标准」，展示题号、满分和评分依据；回到工作台，导入准备好的虚构 JPG。指向新增学生的「查看 / 复核」，说明补充页面入口后关闭。

**口播：**

> 评分之前，要先告诉工具每道题的题号、满分和给分依据。比如不仅写最后答案，也可以写过程分怎么给。常用标准可以保存为模板，下次继续使用。然后导入试卷，支持图片和多页 PDF。这里要注意：每个文件会新建一位学生，所以一份 PDF 只放一位学生的试卷；同一位学生的补充照片，可以在详情里添加。

**字幕：** 一个文件对应一位学生；PDF 支持一位学生的多页试卷。

### 02:25–03:00｜真实 AI 接入在哪里

**画面操作：** 打开「模型设置 → 浏览器直连」，选择 DeepSeek，展示自动填入的服务地址、`deepseek-flash` 及空的密钥输入框。不要点击发送真实请求。随后回到工作台，用顶部考试下拉框切回最初的示例考试。

**口播：**

> 真正批改自己的试卷，需要先配置支持图片的模型。比如选 DeepSeek，地址和模型会自动填好，输入自己的 API 密钥就能测试连接，再用一份试卷试批改。模型服务可能收费，正式结果仍要老师复核。今天先不调用真实模型，下面切回内置示例，展示生成初评之后，老师怎样复核。

**字幕：** 下段使用虚构演示结果；真实模型准确率需另行验证。

### 03:00–04:00｜固定一道题，连续复核不同学生

**画面操作：** 点击「按题复核」→ 选择第 7 题 → 在名单中选择“周子墨”。展示未能辨认的空分数和禁用的确认按钮；补填演示分数 20，再点击「确认本题并下一位」。切换到第 6 题，用学生名单切换两次，展示题号保持不变。

**口播：**

> 你可以按学生看整张试卷，也可以像平时流水阅卷一样，固定一道题，连续看不同学生。左边是原卷，右边是本题的评分依据、AI 初评分和教师得分。无法辨认的答案会留空，需要老师核对，不会直接当成零分。核对后点“确认本题并下一位”，就能继续处理当前筛选里的下一位待复核学生。
>
> 顶部会显示这道题已经复核了多少人。确认一道题，只代表这一题完成；所有题目都有得分并完成复核后，整卷才会进入正式成绩。

**操作提示：** 示例第 7 题中，前两位学生已经确认，第三位未评分。补分确认后可能提示该题队列已完成，这是正常的。为展示跨学生切换，再选择第 6 题即可。左右方向键在没有编辑输入框时也能切换学生。

### 04:00–04:45｜常用评语可以复用，也能继续改

**画面操作：** 在当前题目卡片展开「常用评语」，选择“请补充关键推导或计算步骤，让解题过程更完整”；展示文字追加到教师评语中。关闭复核，进入左侧「常用评语」，展示分类、收藏及中英文编辑框。

**口播：**

> 经常写的反馈，可以放进常用评语库。它分为表扬与肯定、待改进和学习建议，支持搜索、收藏，也能自己新增中英文版本。批改时点一下，就会追加到这道题的教师评语里，不会把原来的内容覆盖掉。老师仍然可以继续修改，让反馈适合这个学生。改分或者改评语之后，这道题需要重新确认，避免修改后漏掉复核。

### 04:45–05:35｜切换历史考试，归档也不丢记录

**画面操作：** 进入「班级与批次」，选择“全部班级”，展示示例考试与新建测验。点击某个班级筛选，再切回全部；用“第四单元”搜索后清空；归档那场新建测验，切换「已归档」，然后取消归档。打开最初示例考试。

**口播：**

> 再回到班级与批次，刚才两场考试都在。可以按班级筛选，也能搜索考试名称或日期。每一场考试会保留自己的试卷、评分标准、分数和复核进度，回来之后能接着批改。已经结束的考试可以归档，平时列表更清爽。归档只整理列表，不会删除；切到“已归档”仍然能打开和继续处理。

### 05:35–06:20｜导出成绩，备份后再换电脑

**画面操作：** 回到工作台点击「导出成绩」，展示“仅已确认成绩（正式）”选项，下载 CSV；进入「班级与批次」点击「备份全部班级」，展示下载的 JSON 文件。无需在录屏中执行整库替换恢复。

**口播：**

> 复核完成后，可以导出成绩 CSV，也可以打印学生反馈、保存成 PDF。这里的正式成绩，只包含已经确认、评分完整、符合当前标准的结果。
>
> 最后一步别忘了备份。记录保存在当前浏览器，不会因为项目放在 GitHub 上，就自动上传或在不同电脑间同步。只保存一场考试，可以用“备份当前考试”；要换电脑，建议“备份全部班级”。恢复单场备份会新增一场考试；恢复全量备份会替换本机整个资料库，所以要先保留好原来的备份。

### 06:20–06:45｜收尾与邀请反馈

**画面操作：** 展示 GitHub 仓库首页及在线入口，再回到班级管理页面。镜头停留 2 秒。

**口播：**

> 这个项目已经开源，中文、英文在线入口和源码都放在简介里。如果你是老师，可以先用虚构示例试试，也欢迎告诉我：你最常批哪一类题、最想减少哪一步重复操作。它提供 AI 初评和整理工具，最终判断仍然交给老师。觉得有帮助，也欢迎收藏视频，或者到 GitHub 提需求。

>
> 先建班级和考试，写好每道题的评分标准，再导入图片或多页 PDF。接入自己的视觉模型以后，可以生成初评，老师再对照原卷修改和确认。
>
> 批改时可以固定一道题，连续看不同学生；常写的反馈放进评语库，一键追加，还能继续编辑。
>
> 这次又加了班级和历史考试管理，新建考试不会清空旧记录，之前的试卷、成绩和复核进度都能找回来，也能搜索和归档。
>
> 不填密钥也能用内置虚构示例体验。真实模型需要自行配置，可能产生接口费用。记录保存在当前浏览器，换电脑前记得备份。项目和中英文入口放在简介里，欢迎老师们试用、提建议。

## 录制后核对

- 保留“示例 / 虚构数据”提示，避免把演示分数说成真实模型实测结果。
- 画面中不出现真实学生资料、个人 API 密钥或其他窗口的私人信息。
- 不把“自动保存”讲成“云同步”，不把“开源代码”讲成“所有模型接口免费”。
- 不承诺所有学科、手写体、图表题都能准确识别；没有实测的准确率和节省时间数据不写进标题。
- 简介中的链接和版本与录制画面一致。
