# Fictional papers for demonstrations / 录屏用虚构试卷

- [中文示例试卷 JPG](demo-paper-zh.jpg)
- [English demo paper JPG](demo-paper-en.jpg)

These images are generated by GradeFlow's built-in demo renderer. Names, answers and markings are fictional. They contain no real student data and are not an accuracy benchmark.

这两张试卷由本项目内置示例生成，学生、答案和试卷均为虚构，可用于演示上传操作。它们不含真实学生信息，也不是批改准确率评测数据。录制成绩复核时，建议切回内置示例；导入 JPG 本身不会产生评分结果。
